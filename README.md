# Cierre Caja

MVP web para registrar ingresos semanales de un comercio.

## Funciones

- Registro de monto.
- Medio de pago: efectivo o transferencia.
- Totales de hoy y de la semana.
- Totales separados por medio de pago.
- Historial de movimientos.
- Deshacer la última venta.
- Borrado automático al abrir la app en una nueva semana.
- Datos almacenados únicamente en el navegador mediante `localStorage`.

## Desarrollo

```bash
npm install
npm run dev
```

Abrir `http://localhost:3000`.

## Deploy

Compatible con Vercel sin variables de entorno ni base de datos.
